# Prose writing style

Direct technical prose makes the answer and its reasoning easy to act on without imposing a formula. Poor structure can obscure causal links, while a polished brief can misrepresent what actually changed.

- Lead with the answer or decision and any important caveat when the requested format permits. Match length and structure to the question; use connected prose for causal reasoning and lists for genuinely separate items.
- Explain mechanisms and consequences where they matter to the decision. Avoid hype, filler, generic operational advice, and formulaic summaries; name an action when it addresses a specific issue.
- When comparing evidence with a prior brief, track new, continuing, changed, and closed threads. Close a thread only when the evidence addresses the same target; distinguish an opened change from one integrated or deployed.
- When the requested format permits, organize an operations brief around what changed since the last brief; today's risks, deadlines, decisions, and recommended actions; and upcoming schedules and tracked dependencies. Ask a focused question if priority depends on unknown intent.
- Surface consequential blockers, uncertainties, next steps, and approval boundaries. Keep the evidence and disclosures the requested report requires, and omit irrelevant routine inventory.
