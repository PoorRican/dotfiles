# Paired Execution Controls

For an execution-only comparison, latch the common first qualifying signal before applying arm-specific execution gates. Keep signal selection, submission, and fill separate: an arm that cannot execute must not substitute a later signal. Record current eligibility independently of earlier refusal precedence so the healthy-opportunity denominator remains observable.

Test refusal followed by stronger and opposite signals, pending and unfilled submissions, and eligibility recovery. Mechanical replay evidence does not by itself qualify economic results.
