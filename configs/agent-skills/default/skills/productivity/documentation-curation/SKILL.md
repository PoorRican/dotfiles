# Documentation curation

The common failure is trusting polish, recency, or a narrow edit instead of checking what each claim means and where it is relied on. Competing versions can both be wrong, omissions are not contradictions, and accurate rewrites can still lose valid material. The references separate source-grounded adjudication, cross-document contract changes, record consolidation, content conservation, and fact-checked documentation; they preserve the reasoning without imposing a fixed workflow.

The references cover documentation-specific claim accounting and source verification; general review criteria are outside this index.
