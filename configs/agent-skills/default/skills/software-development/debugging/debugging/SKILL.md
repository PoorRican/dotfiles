# Debugging

Debugging locates the cause of unexpected behavior rather than patching the first visible symptom. Boundaries and asynchronous execution can conceal the original failure. For Linux authentication, devices, memory, filesystems, GPU drivers, or supervised processes, use the `linux-system-debugging` skill.

| When | Reference |
|---|---|
| Tracing failures, process exceptions, HTTP responses, Python breakpoints, asynchronous waits or pollers, or native output | [Root-cause tracing](references/root-cause-tracing.md) |
