# Agent Orchestration

Orchestration divides work into independently actionable boundaries and joins the evidence and changes back together. Overlapping ownership, implicit interfaces, and unverified handoffs can produce incompatible work or misleading results.

| Task | Reference |
|---|---|
| Partition work, manage shared resources, or integrate streams | [Fan-out design](references/fanout-design.md) |
| Audit repository boundaries at pinned revisions | [Pinned-tree boundary audits](references/pinned-tree-boundary-audits.md) |
| Brief reviewers, plan handoffs, or implement dependent issues | [Plans and reviews](references/plans-and-handoffs.md) |
| Recover work or investigate earlier sessions | [Recovery](references/recovery.md) |
