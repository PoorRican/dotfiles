# omp runtime recipes

Small harness behaviors that cost a session when guessed: settings discovery that does not walk ancestors, helper aliases that silently substitute a model, and read-only reviewers that cannot write the report they were asked for. Read the installed version's docs (`omp://settings.md`, `omp://memory.md`) and check current CLI and config keys before relying on any key below.

| When you are… | Open |
|---|---|
| Enabling or disabling omp settings or a memory backend only under one workspace tree | [references/directory-scoped-config.md](references/directory-scoped-config.md) |
| Running a read-only analysis on a model role the user named, with proof of which model actually ran | [references/exact-model-analysis.md](references/exact-model-analysis.md) |
| Saving a completed read-only reviewer's strict JSON, or recovering it after a failed batch | [references/subagent-output-capture.md](references/subagent-output-capture.md) |
